## 📌 Project Overview

The Shopping Cart Management System is a Java console-based application developed using Object-Oriented Programming (OOP) concepts. It allows users to manage products in a shopping cart by adding, searching, updating, viewing, removing, and checking out items.

This project demonstrates the use of Java classes, objects, methods, `ArrayList`, loops, conditional statements, and user input handling with `Scanner`.

## ✨ Features

* Add products to the shopping cart
* View all products in the cart
* Search products by Product ID
* Update product quantity
* Remove products from the cart
* Calculate subtotal and grand total
* Checkout and clear the cart
* Menu-driven console interface

## 🛠️ Technologies Used

* Object-Oriented Programming (OOP)

## ▶️ How to Run

1. Clone the repository.
2. Open the project in any Java IDE (Eclipse, IntelliJ IDEA, VS Code, or NetBeans).
3. Compile the program:

   ```
   javac shoppingcart.java
   ```
4. Run the program:

   ```
   java shoppingcart
   ```
